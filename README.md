# Pearl Fragment (the JRPG prototype)

A pirate JRPG in the browser: wash up on a living island, build a city on it, swallow pearl fragments, sail the
first sea and fight turn-based battles with timed attacks, dodges and parries.
**Play it at https://demidummy.github.io/pearl-fragment-jrpg/**

Keyboard and mouse. Esc opens the menu and How to play.

This repo only holds the built game. It's published from a private source repo by `tools/release-pages.sh`.
